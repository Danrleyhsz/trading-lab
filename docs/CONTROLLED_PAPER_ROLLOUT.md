# Controlled paper rollout, before any continuous cycle

The human authorized eight independent wallets, sourced research/studies, recovery validation and controlled paper, stopping before continuous execution. The launcher defaults to the unchanged FIRST_PUBLICATION policy. Explicit CLOUD_LAUNCH_PHASE=CONTROLLED_PAPER permits PERPETUAL_PAPER_ENABLED=true only with explicit independent-wallet allocation and positive virtual capital. All other execution flags and autonomy remain false; AUTONOMOUS_STUDY_ID must remain absent. TLS, protected HTTPS, PostgreSQL, source and no-paid/private-key checks remain required. No configuration check certifies backups or grants risk approval.

Before changing production flags: identify reviewed commit/green CI, verify durable eight-wallet allocation and unchanged fund, preserve sourced research/study IDs, obtain a logical backup and test recovery separately, restart and compare retained IDs/endowments/ledgers. Do not overwrite production, upload history to GitHub or import development fixtures. Check actual effective database network restrictions, single writer, current quotes and confirmed writes. Provider backup availability alone is not a restore drill.

After operational acceptance and publication approval, keep PAPER_EVALUATION_ENABLED=false, LEGACY_PAPER_EXECUTION_ENABLED=false, AUTONOMOUS_PERPETUAL_ENABLED=false, no autonomous study and no AI provider. Controlled independent USD-M orders use the existing authenticated account endpoint and deterministic risk. First exercise a small explicitly bounded paper entry and matching reducing close, record original proposal/risk/fill IDs, actual observed prices/fees, and reconcile closed performance, cash, audit and unchanged fund. Never manufacture profitable studies or call historical results account P&L. Stop on missing evidence, stale source, failed persistence or unavailable reduction; retain the failure.

This increment is preparation, not production activation. No scheduled loop, new paid resource, credential or schema is introduced. The user must explicitly authorize the later continuous cycle; this release cannot enable it.
